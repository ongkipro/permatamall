Akses, session, dan role.

Login menggunakan D1 credential, PBKDF2 verification, JWT, dan versioned KV session. Bootstrap account dipaksa mengganti username dan password.

Owner

Mengelola seluruh operasi tenant, account, provider configuration, dan collaborator access.

Collaborator

Mendapat delegated scope yang tersimpan di D1. Tidak mewarisi owner-only mutations.

Unauthenticated

/admin/* kembali ke /hello. Protected API memberi JSON 401.

POST login

Validasi credential dan forced-change state.

JWT + KV session

Signed token menunjuk session aktif yang dapat direvoke.

Middleware

Verifikasi session, role, dan route boundary.

POST logout

Hapus session server-side lalu redirect ke login.

Measurement mengikuti order lintas frontend.

Astro, Shopify, WordPress, React, atau HTML dapat mengirim browser event. CMSAds tetap menyatukan Pixel, server CAPI, GTM, payment, product, dan order melalui canonical D1 identity.

Browser events

PageView, ViewContent, AddToCart, InitiateCheckout, dan Purchase. Advanced Matching memakai normalized hashed identifiers.

Order + payment truth

D1 order ID, invoice, product ID, total, payment status, dan purchase_event_id mengendalikan qualified event.

Destinations

Meta Pixel + CAPI memakai matching event_id. GTM memakai dataLayer. Duplicate Purchase diblok client guard.

Catalog alignment: content_ids memakai canonical numeric product ID D1, bukan slug atau SKU.
Online Purchase: event menunggu reconciliation payment nyata. Unknown order menghasilkan 404, bukan synthetic unpaid state.
Frontend adapter contract: storefront memuat tenant ads configuration, memakai canonical product ID, mempertahankan event_id dan click identifiers, lalu mengirim submit-order pada origin tenant yang sama.

UI state contract.

Setiap layar operation harus menjelaskan apa yang sedang terjadi, bukan hanya menampilkan tombol.

Loading

Skeleton menyerupai final layout dan mempertahankan density.

Empty

Menjelaskan apakah data kosong karena filter, belum ada order, atau belum ada configuration.

Error

Actionable reason tetap dekat dengan row. Successful bulk sibling tidak di-rollback.

Selection

Dimulai kosong. Filter-aware master, partial state, count, clear, dan explicit action selalu terlihat.

Responsive

Desktop memakai table saat sesuai. Mobile memakai card tanpa nested horizontal overflow.

Accessibility

Touch target minimal 44px, visible focus, 16px form input, keyboard command search, dan explicit labels.
