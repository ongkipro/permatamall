Ads Tracking

Sinyal konversi dengan identitas konsisten.

Pixel browser dan Conversions API dapat memakai event ID yang sama untuk deduplikasi. CMSAds memvalidasi payload dan status order; acceptance, deduplication, atribusi, dan hasil campaign tetap harus dibuktikan terpisah.

Event Identity & Parameter

Menangkap jejak klik tanpa kehilangan atribusi lintas halaman.

Setiap event memakai identitas yang sesuai kontrak, bukan satu ID sesi untuk semua funnel:

event_id

ID unik per event. Browser dan CAPI Purchase memakai Purchase event ID yang sama; funnel event ID tidak boleh dipakai ulang.

_fbp & _fbc

Identifier atribusi Meta diteruskan dalam bentuk raw saat tersedia. Keduanya tidak di-hash.

Advanced Matching

Phone dan nama dinormalisasi lalu di-hash SHA-256 sebelum CAPI. IP dan user agent berasal dari batas server.

Catalog identity

content_ids memakai ID product D1 yang sama di Pixel, CAPI, dan Meta Commerce Catalog.

Browser vs CAPI (Deduplication)

Dua jalur sinyal memakai identitas sama; tidak ada jaminan provider menerima atau mengatribusikannya.

Storefront (Browser)

Pixel Purchase setelah CMSAds mengonfirmasi state yang memenuhi syarat.

event_id: purchase_order_123

Meta

Provider membandingkan nama event dan event_id. Acceptance dan dedup harus diperiksa, bukan diasumsikan.

CMSAds (Server)

CAPI memakai Purchase event ID yang sama dan credential server-only.

event_id: purchase_order_123

Purchase Gates

Kapan event Purchase benar-benar dipicu?

Metode Pembayaran Sinyal Checkout Sinyal Purchase (Browser + CAPI)
Cash on Delivery (COD) InitiateCheckout saat submit valid dimulai. Qualified Hanya setelah order berhasil dipersist oleh CMSAds. Konfirmasi shipping tidak membuat Purchase kedua.
Bank Transfer / VA InitiateCheckout saat submit valid dimulai. Gated Hanya setelah callback AutoLaris terautentikasi merekam status paid.
Backend authority: storefront tidak menentukan kelayakan Purchase. Browser boleh mengirim Pixel Purchase hanya setelah respons/status CMSAds mengonfirmasi order yang memenuhi syarat; CAPI memakai event ID yang sama.
