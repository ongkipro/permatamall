SERVICE-ONLY

Headless production tenant

CMSAds tidak memiliki Custom Domain atau zone route. Storefront Worker memiliki domain dan memanggil CMSAds lewat private service binding. Deploy backend tidak mengganti public UI.

CUSTOM-DOMAIN

Integrated atau preview tenant

CMSAds memiliki exact Custom Domain dan dapat merender storefront sekaligus admin/API. Deploy Worker ini dapat mengubah public surface.

Validator: service-only dengan public route ditolak. custom-domain tanpa exact route yang cocok dengan canonical origin juga ditolak.

Menambahkan tenant baru.

Installer membuat tenant custom-domain secara default. Headless production membutuhkan storefront Worker dan service binding yang dirancang terpisah sebelum CMSAds diubah menjadi service-only.

# 1. Preview plan tanpa side effect
npm run tenant:install -- --plan \
  --slug merchant-b \
  --domain shop.example.com \
  --name "Merchant B" \
  --owner-name "Merchant Owner" \
  --owner-email owner@example.com \
  --template wide-catalog

# 2. Provision hanya setelah approval
npm run tenant:install -- --yes \
  --slug merchant-b \
  --domain shop.example.com \
  --name "Merchant B" \
  --owner-name "Merchant Owner" \
  --owner-email owner@example.com \
  --template wide-catalog

Sesudah provision

  1. Pilih integrated custom-domain atau headless service-only.
  2. Untuk headless, deploy storefront Worker, route domain, dan service binding lebih dahulu.
  3. Review Worker, ingress, D1, KV, R2, dan AI identities.
  4. Set secrets tanpa mencetak atau commit nilainya.
  5. Ganti bootstrap credential pada login pertama.
  6. Integrasikan ads config, location, ongkir, submit order, dan attribution ke frontend.
  7. Gunakan --publish hanya jika deployment juga disetujui.
Input required: sistem tidak membuat merchant palsu, content instruction palsu, product catalog palsu, atau creative palsu untuk mengisi tenant baru.

Failure dan rollback boundary.

Missing contract

Build gagal jika binding atau public variable wajib tidak ada.

Unknown tenant

CLI berhenti sebelum child process dijalankan.

Failed smoke

Stop. Simpan output, jangan broaden release, dan jangan claim completion.

Rollback

Worker rollback tidak otomatis membalik D1 migration atau external provider side effect.

Breaking API

Storefront visual tetap tayang, tetapi checkout dapat gagal. Rollback atau migrasikan seluruh adapter sebelum memperluas deploy.
