ONLINE

Checklist bulk di Shipping.

Selection dimulai kosong, mengikuti filter aktif, dan tidak menjalankan action sampai operator menekan Push.

Navigation selection

  • Semua push: pilih row visible dan dispatchable.
  • Semua pickup: pilih row visible yang ready untuk pickup.
  • Partial state: master checkbox menjadi indeterminate.
  • Bersihkan: reset selection tanpa mutation.
  • Action buttons: Push N atau Pickup N tetap explicit.

Snapshot eligible order IDs

Backend memvalidasi warehouse ownership, current state, eligibility, dan claim lease.

Jalankan satu request

Build payload dari order, item, warehouse, destination, courier, COD, dan declared value.

Tunggu response settle

Request berikutnya tidak dimulai sebelum request saat ini selesai. Parallel POST /order dilarang.

Commit hasil per order

Successful sibling tetap committed. Failed atau skipped order tetap visible dengan alasan untuk retry.

Response state tidak disederhanakan.

Bulk bukan satu transaksi all-or-nothing. Setiap order menghasilkan outcome sendiri.

OutcomePersistenceOperator melihat
successProvider order ID disimpan. cnote_no hanya jika tersedia.Shipment accepted, courier, service, waybill jika issued.
unpaidAccepted provider draft, isPaid: false, cnote dapat kosong.Draft unpaid, bukan dispatched dengan resi.
skippedTidak ada provider mutation.Reason seperti state berubah, already claimed, atau ineligible.
failedprovider_dispatch_error disimpan, state tetap processing.Error actionable dan retry control. Sibling success tidak dibatalkan.
Provider 409: satu order dianggap gagal. Sistem tetap sequential dan tidak menyalakan parallel retry.

Pickup, tracking, dan batas provider.

Pickup scheduling

Partially integrated

UI dan D1 schedule tersedia. Time harus minimal 90 menit dari sekarang. Local row tidak boleh disebut Mengantar-confirmed sebelum provider /address dan /time sync terverifikasi.

Tracking sync

Blocked

Official callback atau polling endpoint, authentication, retry semantics, dan status enum belum tersedia. Tidak ada webhook atau mapping status yang dibuat dari asumsi.

Unpaid recovery

Contract unverified

/order/pay-unpaid belum diekspos karena request, response, authentication, dan idempotency contract belum terverifikasi.

Wallet balance

Blocked

Tidak ada canonical wallet endpoint yang terverifikasi. UI balance CMSAds hanya recorded payment ledger AutoLaris, bukan Mengantar wallet.
