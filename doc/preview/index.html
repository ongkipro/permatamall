Repository dan application contract dibagi. Setiap deployment tetap mengunci request ke Worker, admin/API, D1, KV, R2, AI, secrets, dan provider configuration milik satu tenant.

Admin, API, schema, order, shipping, payment, tracking guard, CLI, tests, dan release workflow.

Exact tenant Worker

Scale-out

Checkout frontend

API memvalidasi customer, variant, rate, stock, attribution, dan harga. Order disimpan sebagai pending.

Order Management

Edit alamat, cari kecamatan atau kota, pilih kelurahan, kurir, dan konfirmasi kesiapan.

Shipping

Order processing masuk antrean. Operator memilih checklist Push dan menjalankan dispatch sequential.

Mengantar
